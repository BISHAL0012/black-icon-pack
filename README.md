# Black Round Icons

Nothing-style icon pack: white minimal glyphs on black rounded tiles.

- 25 themed icons (Facebook, WhatsApp, Telegram, YouTube, Instagram, Free Fire, Roblox and more)
- Icon mask included: apps without a themed icon are auto-fitted into the same black rounded style by the launcher

Apply with Lawnchair or Nova Launcher (Settings > Icon style / Theme).
The APK is attached to the v1.0 release, built by GitHub Actions.
